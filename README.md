# Optimus Pepe ($OPTIPEPE)

Static landing page for Optimus Pepe.

## Live site

GitHub Pages deploys automatically on every push to `main`.

## Update & deploy

From this folder, run:

```powershell
.\deploy.ps1
```

Or manually:

```powershell
git add -A
git commit -m "Update Optimus Pepe site"
git push
```

Pages rebuilds from the Actions workflow after each push.
